# OpenSCAD: programmatisk 3D-modellering

Kode til guiden **[OpenSCAD: programmatisk 3D-modellering](https://robonordic.no/openscad-programmatisk-3d-modellering-for-ingeniorer/)** på robonordic.no.

| Fil | Hva den gjør | Merk |
|---|---|---|
| `skrue.scad` | Skrue som gjenbrukbar modul med parametere | Åpne i OpenSCAD, F6 for å rendre |
| `teknisk_boks.scad` | Parametrisk boks med skruehull i hjørnene | Endre målene øverst, eksporter STL |

**Plattform:** OpenSCAD
