# G-code grunnleggende

Kode til guiden **[G-code grunnleggende](https://robonordic.no/g-code-grunnleggende-forstaa-cnc-maskinens-spraak/)** på robonordic.no.

| Fil | Hva den gjør | Merk |
|---|---|---|
| `firkant.nc` | Freser en firkant på 20 × 20 mm, 2 mm dyp | Test i luften før du fresen i materiale |

**Plattform:** CNC (GRBL o.l.)

Kjør alltid programmet i luften først, og sjekk spindelhastighet og mating mot maskin og materiale.
