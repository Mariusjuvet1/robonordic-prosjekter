# PID-regulering i praksis

Kode til guiden **[PID-regulering i praksis](https://robonordic.no/pid-regulering-i-praksis-kontroller-motorer-og-temperaturer/)** på robonordic.no.

| Fil | Hva den gjør | Merk |
|---|---|---|
| `01_pid_analog` | PID-sløyfe: måler på A0, pådrag med PWM på pinne 9 | Krever biblioteket «PID» (Brett Beauregard) |

**Plattform:** Arduino UNO

Installer biblioteket i Arduino IDE: Tools → Manage Libraries → «PID».
