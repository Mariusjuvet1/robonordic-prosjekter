# XIAO ESP32-C3

Kode til guiden **[XIAO ESP32-C3: Kraftig mikrokontroller i miniformat](https://robonordic.no/xiao-esp32-c3-kraftig-mikrokontroller-i-miniformat/)** på robonordic.no.

| Skisse | Hva den gjør |
|---|---|
| `01_wifi` | Kobler til WiFi |
| `02_dyp_sovn` | Legger brikken i dyp søvn i 60 sekunder – ved oppvåkning starter `setup()` på nytt |

Velg kortet **XIAO_ESP32C3** i Arduino IDE (ESP32-kjernen fra Espressif). Bytt ut nettverksnavn og passord i `01_wifi`.
